# SAATHI — AI-Powered Dynamic Distress Monitoring Platform

Polished React/Vite/Tailwind prototype for a beneficiary → AI-assisted analysis → alert → counsellor review → intervention demo flow.

## Stack
- React + Vite
- Tailwind CSS via `@tailwindcss/vite`
- React Router
- Recharts
- Lucide React
- localStorage only; synthetic data

## Run
```bash
npm install
npm run dev
```

## Demo flow
1. Open the app and choose Beneficiary.
2. Start a daily check-in and submit responses.
3. The prototype calculates a synthetic distress score and updates the latest case.
4. Switch to Counsellor.
5. Review the generated alert/case.
6. Open the case, inspect the trend and AI indicators, then record a human intervention.

All AI outputs are explicitly labelled as prototype analysis and not medical diagnosis.
